# 가족 경유지 기록과 휴대폰 공유

Route94에 추가한 가족 나들이·여행 기록 기능 설명입니다. 현재 구현 범위는 **이동 경로와 경유지를 기록하고, 마음에 든 곳에 별표·메모를 남긴 뒤 휴대폰과 CSV로 확인하는 것**입니다.

## 1. 기능의 목적과 범위

나들이 중 들른 장소와 그때의 경험을 나중에 다시 찾을 수 있도록 남깁니다. 기존 업무용 운행일지와 같은 앱에서 동작하지만 기록은 별도로 관리합니다.

- 이동 GPS 경로와 기어 P 전환 시점의 경유지를 자동 수집합니다.
- 경유지에 ‘발자국’ 별표와 메모를 남깁니다.
- 주행 중에 마음에 든 곳을 버튼이나 음성으로 바로 저장합니다.
- 차량 화면에서 이동 경로와 경유지를 함께 확인합니다.
- QR 하나로 고른 방문의 위치를 지도 앱에서 바로 엽니다.
- QR로 휴대폰에 기록을 펼치고 카카오맵에서 저장된 위치를 엽니다.
- `휴대폰으로 받기`의 `엑셀`에서 Excel 호환 CSV를 받습니다.

자체 길 안내, 취향 기반 장소 추천, 카카오계정 로그인·즐겨찾기 동기화는 포함하지 않습니다.

## 2. 차량에서 사용하는 흐름

### 자동 기록

1. 개인정보 수집·이용에 동의합니다. 동의 전에는 차량·위치·음성을 수집하지 않습니다.
2. 앱이 실행 중이고 기어 상태가 확인되면 날짜별 기록이 자동으로 만들어집니다. 별도의 ‘여행 시작’이나 ‘여행 종료’ 조작은 필요하지 않습니다.
3. GPS 위치를 수집해 이동 경로를 남깁니다. 좌표는 약 15초 간격으로 저장합니다.
4. 기어가 P로 바뀌면 도착 시각과 가능한 경우 주차 좌표를 경유지로 남깁니다. 다시 이동하면 출발 시각을 기록합니다.
5. 다음 날짜에 차량 신호를 받으면 새로운 날짜의 기록을 만듭니다. 지난 날의 기록은 별표한 곳과 그 메모만 남기고 경로와 나머지 방문은 지웁니다.

앱이 꺼져 있던 구간의 이동이나 체류 시간을 추정하지 않습니다. 앱 재실행 시 이전의 열린 방문을 ‘기록 중단’으로 표시하고 경로를 끊어 연결합니다. 같은 주차 위치에서 앱을 다시 실행하면 별도 관측 기록이 생길 수 있습니다.

### 경유지 확인·저장

- 상단의 **발자취** 탭에서 오늘의 방문 항목을 선택합니다. 왼쪽 위 `오늘 발자취 | 발자국` 전환으로 지난 날에 별표한 곳 목록을 봅니다.
- 별(**발자국 남기기**)을 눌러 즐겨찾기를 표시합니다.
- **음성 메모** 또는 **메모 수정**으로 경험을 남깁니다.
- **주차 위치 주변 검색**은 주차 좌표 주변의 음식점·카페·명소 후보를 조회합니다. 방문한 장소는 사용자가 확인합니다.

기록 수집은 이동 중에도 진행하지만 장소 수정·메모·공유는 기어 P가 확인된 상태에서만 가능합니다. 기어를 알 수 없을 때도 수정·공유를 제한합니다.

### 주행 중 찜하기

앱은 `distractionOptimized`(DO)를 선언해 주행 중에도 시스템에 가려지지 않습니다. 대신 기어가 P가 아니거나 차량의 주행 제한 신호(`CarUxRestrictions`)가 켜지면 다른 화면과 창을 모두 숨기고 **여기 저장**, **말하기** 버튼만 있는 전용 화면을 보여 줍니다. 개인정보 동의 전이면 "정차한 뒤 동의해 달라"는 안내만 표시합니다.

- **여기 저장**을 누르거나 **말하기** 후 "여기 기억해 줘"라고 말하면 그 순간의 위치를 별표 장소로 저장하고 음성으로 알려 줍니다. "기억해 줘", "찜해 줘", "괜찮은데"도 같은 명령으로 처리합니다.
- 저장되는 좌표는 **그 장소가 아니라 그때 차가 있던 위치**입니다. 정차 후 **주차 위치 주변 검색**으로 실제 장소를 고를 수 있습니다.
- GPS가 없으면 시각과 내비 주소만 저장합니다. 10초 안에 다시 요청하면 한 건으로 처리합니다.
- 호출어는 없어서 버튼을 한 번 눌러야 합니다.
- 휴대폰 보기와 CSV에는 "지나가다 찜한 곳", 체류 0분으로 나옵니다.

**출시 전 확인 필요:** Android는 선언만 확인하고 실제 동작은 검사하지 않으며, Pleos는 카테고리·주행 상태·지역에 따라 주행 중 허용 범위가 달라지고 심사에서 반려될 수 있다고 안내합니다. 현대차 오너스 매뉴얼은 App Market 앱을 주행 중 사용할 수 없다고 예외 없이 설명하므로, 이 기능의 출시 가능 여부는 Pleos 측 확인이 필요합니다.

### 지도 미리보기와 즐겨찾기

차량 화면은 도로 지도 대신 수집한 GPS 좌표를 선으로 그리는 미리보기입니다. 번호는 오른쪽 방문 목록의 번호와 같습니다.

- 오른쪽에서 3번 방문을 선택하면 지도도 같은 기록을 선택합니다. 그 기록이 즐겨찾기라면 **`3 ★`**로 표시합니다.
- 표식이 겹치면 선택된 방문을 우선 표시하고, 선택된 방문이 없는 묶음에서는 즐겨찾기를 우선 표시합니다.
- **같은 위치 N곳** 버튼을 누르면 겹친 표식의 방문 목록에서 기록을 직접 선택할 수 있습니다. 원래 좌표와 방문 번호는 유지합니다.

## 3. 휴대폰 보기와 엑셀 내보내기

두 기능은 별도 버튼·화면으로 제공합니다. 같은 기록을 사용하지만 휴대폰 보기 화면이 엑셀 표와 같을 필요는 없습니다.

| 기능 | 차량에서 누르는 버튼 | 휴대폰에서 할 수 있는 일 |
|---|---|---|
| 여행 기록 보기 | 휴대폰으로 받기 → 여행 기록 | 방문 장소·시각·별표·메모를 카드로 확인, 카카오맵 열기 |
| Excel 호환 파일 받기 | 휴대폰으로 받기 → 엑셀 | 표 확인, CSV 다운로드, 인쇄·PDF |

### 지도 QR

**휴대폰으로 받기**의 `이 장소 지도`는 위 두 기능과 달리 웹페이지를 거치지 않습니다. QR에 지도 링크가 바로 담겨 있어 호스팅 없이 동작하며, 정차(P) 중에만 열립니다.

| 지도 | QR에 담기는 링크 | 앱이 없을 때 |
|---|---|---|
| 카카오맵 | `kakaomap://look?p=위도,경도` | 열리지 않을 수 있음 |
| 네이버 지도 | `nmap://place?lat=위도&lng=경도&name=이름&appname=앱 ID` | 열리지 않음 |
| 구글 지도 | `https://www.google.com/maps/search/?api=1&query=위도,경도` | 브라우저에서 열림 |

좌표가 없으면 주소와 이름으로 검색합니다. 고른 지도는 저장되며 동의 철회 시 함께 삭제됩니다. QR에 별표와 메모는 담기지 않습니다. 네이버 지도는 대한민국 범위의 좌표만 받으므로 에뮬레이터 기본 GPS(미국)로 저장된 기록은 열리지 않습니다.

### 카카오맵 연결

휴대폰의 **카카오맵 앱에서 위치 보기**는 `kakaomap://look?p=위도,경도`로 저장 좌표를 앱에 직접 전달합니다. 카카오 웹페이지나 스토어의 일반 ‘열기’ 버튼을 거치지 않습니다. 웹으로 보는 링크도 별도로 제공합니다.

좌표가 없고 장소명·주소만 있으면 카카오맵 검색으로 연결합니다. 위치를 확인할 정보가 없으면 지도 링크를 만들지 않습니다. 좌표는 수집된 **주차 위치**이며 실제 방문 장소의 출입구와 다를 수 있습니다. 앱 전용 링크를 여는 데 장소 검색용 API 키나 카카오 로그인이 필요하지는 않습니다.

### CSV 구성

CSV는 한글을 위한 UTF-8 BOM을 포함합니다. Excel에서 열 수 있으며 `.xlsx`가 필요하면 Excel에서 다른 이름으로 저장합니다.

포함 항목은 기록 구분(실제/예시), 기록명, 시작·종료 시각, 시간대, 수집 GPS 거리, 방문 순서, 장소명·주소, 도착·출발 시각, 체류 시간, 기록 상태, 즐겨찾기, 메모, 주차 위도·경도입니다. 메모의 쉼표·따옴표·줄바꿈을 보존하고 수식으로 해석될 수 있는 문자열을 처리합니다.

원시 이동 경로 전체의 좌표열은 휴대폰 링크와 CSV에 포함하지 않습니다. 기록이 길면 여러 QR로 나누므로 모든 QR을 스캔하고 각각의 파일을 받아야 전체 방문을 보관할 수 있습니다. 차량에 실제 문서 저장 선택기가 있으면 전체 기록을 한 CSV 파일로 저장할 수도 있습니다.

## 4. QR 데이터와 웹 호스팅의 역할

```text
차량에 저장된 기록 → 압축 데이터가 담긴 QR 링크
                              ↓ 휴대폰으로 스캔
                정적 웹페이지 → 휴대폰 안에서 기록 표시·CSV 생성
```

기록은 URL의 `#` 뒤에 압축해 담습니다. 이 부분은 웹페이지를 요청할 때 서버로 전송되지 않습니다. 웹 호스팅은 화면과 스크립트 파일을 제공하며 여행 기록 저장 서버로 사용하지 않습니다. 링크를 공유하면 다른 사람도 해당 기록을 열 수 있고, 이미 꺼낸 사본은 차량의 동의 철회로 삭제되지 않습니다.

기존 호스팅은 `https://pleos-note.vercel.app/`입니다. 여행 화면은 `/journey.html`, CSV 화면은 `/journey-csv.html`을 사용합니다. 다만 **현재 여행 페이지의 공개 배포는 완료되지 않았습니다.** 선행 웹 커밋의 배포가 Vercel에서 `Deployment was blocked`로 차단됐습니다. 저장소가 비공개이고 Vercel이 Hobby 요금제라서 프로젝트 소유자(`ysna629`)가 작성한 커밋만 배포되기 때문입니다. 최신 보완 사항은 이 기능 브랜치에 포함합니다.

현재 휴대폰 테스트는 Mac의 로컬 서버로 진행했습니다. 같은 Wi-Fi에서 다음과 같이 실행할 수 있습니다.

```sh
python3 -m http.server 8766 --bind 0.0.0.0 --directory viewer
adb shell am force-stop --user 10 ai.pleos.challenge.arrival
adb shell am start --user 10 -n ai.pleos.challenge.arrival/.MainActivity \
  --es viewer_url http://<Mac의-LAN-IP>:8766/
```

예시 화면은 마지막 명령에 `--ez journey_demo true`를 추가합니다. 예시 데이터는 실제 기록과 분리되고 화면에도 예시임을 표시합니다.

## 5. 음성 기능의 현재 상태

Pleos SpeechToText의 온디바이스 모드를 사용합니다. 현대차 기본 음성비서의 전체 대화 흐름을 호출하는 방식은 아니며, 인식된 문장은 앱의 명령 규칙으로 처리합니다. 상시 호출어 감지는 구현하지 않았고 **말하기** 버튼으로 시작합니다.

| 예시 발화 | 동작 |
|---|---|
| 여행 기록 보여줘 | 여행 기록 화면 열기 |
| 여기 기억해 줘 | 정차 중: 현재 경유지 별표 저장 후 음성 메모 질문. 주행 중: 현재 위치를 찜한 곳으로 저장 |
| 휴대폰으로 보여 줘 | 휴대폰 보기 QR 열기 |
| 엑셀로 내보내 줘 | 별도 CSV 내보내기 화면 열기 |

실제 Mac 마이크 입력과 녹음을 통한 실제 STT 처리 모두 확인했습니다. 다만 **첫 단어 누락·부분 인식·제한적인 표현 해석 문제가 남아 있습니다.** 인식 준비 전에도 ‘듣고 있어요’가 표시되는 점도 확인했으나 수정은 보류했습니다. 사용자 요청에 따라 우선 버튼으로 기능을 검증한 상태이며, 음성 사용성까지 완성됐다고 보지는 않습니다.

직접 목소리 테스트는 `adb emu avd hostmicon`으로 호스트 마이크를 켠 뒤 `demo_script` 없이 실행합니다. `journey_*.pcm`은 실제 STT에 넣는 시뮬레이션용 샘플이며 직접 마이크 테스트와 구분합니다.

| 주행 화면 | 에뮬레이터 D에서 전용 화면만 표시, 제한 신호 수신, 동의 전 안내 표시, P 복귀 시 원래 화면 확인 |
| 주행 중 저장 | 에뮬레이터 D에서 버튼 저장과 녹음 문장의 STT 음성 저장, 연속 탭 1건 처리 확인 |

남은 과제는 음성 인식·명령 해석 개선, 공개 호스팅 배포 차단 해결, 실제 차량 환경 검증, 주행 중 기능의 App Market 허용 여부 확인입니다. 주행 중 음성은 녹음 문장으로만 확인했으며 실제 주행 소음 환경은 검증하지 못했습니다. Pleos 에뮬레이터는 문서 선택기가 placeholder라 차량 직접 파일 저장은 검증하지 못했습니다. 카카오 주변 장소 검색은 로컬 API 키 설정이 필요하며 실제 키로 연결한 검증은 하지 않았습니다.

GPS 경로에는 최대 2,400개 좌표를 유지하는 상한이 있습니다. 수집 거리는 저장된 GPS 좌표 사이의 거리로 계산하며 계기판 주행 거리와 같지 않습니다. 장시간 기록·GPS 오차·터널·앱 종료·실제 주행 환경에서의 추가 검증이 필요합니다.

## 7. 발전 방향

제출 범위는 기록과 공유에 집중합니다. 이후 저장된 방문·별표·메모를 바탕으로 가족 취향에 맞는 장소를 엄선하고, 음성 요청으로 후보를 조회하거나 기본 내비게이션으로 연결하는 방향을 검토할 수 있습니다. 이 추천·길 안내 연동은 현재 구현된 기능에 포함하지 않습니다.
