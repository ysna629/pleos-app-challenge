# 여행 방문 기록 CSV 내보내기

사용자는 방문 장소와 즐겨찾기를 도착노트에 보관하는 방식을 승인했고 Excel/CSV로 기록을 꺼내는 방법을 요청했다. 현재 앱의 여행 화면에 CSV 내보내기를 통합한다. 새 앱이나 계정은 만들지 않는다.

## 제공 방식

- P에서 선택한 여행의 방문 목록을 CSV로 저장한다. Android 문서 저장 선택기를 사용하며 저장 위치를 사용자가 결정한다. 선택기가 없는 차량에서는 QR 방법을 안내한다.
- 같은 대화상자에서 휴대폰 QR을 제공한다. 기존 정적 viewer의 별도 여행 페이지를 재사용 호스팅 경로에 추가한다. 데이터를 raw deflate/base64url fragment로 담아 전송하고 서버에 여행 데이터를 올리지 않는다. 페이지 배포는 이 작업에서 수행하지 않는다; 로컬 테스트 URL과 게시 필요 조건을 문서화한다.
- QR 제한을 넘으면 방문 목록을 순서대로 분할하고 각 파일/화면에 전체 파트 수와 원래 방문 번호를 표시한다. 누락/잘림 없이 모든 파트를 저장할 수 있게 한다. 직접 저장 CSV는 전체 방문을 한 파일로 저장한다.

## 내용과 처리

방문당 한 행: 기록 구분(실제/예시), 여행명, 여행 시작/끝, 시간대, GPS 수집 거리, 방문 순서, 장소명, 주소, 도착/출발 시각, 체류분, 기록 상태(완료/머무는 중/중단), 즐겨찾기, 메모, 위도/경도. 실제 이동경로의 원시 좌표열은 이번 방문목록 CSV에 포함하지 않는다. 열린 방문은 내보내기 시점까지의 체류분, 앱 중단으로 끝을 모르는 방문은 체류분 공란으로 표시한다.

UTF-8 BOM, CRLF 및 CSV 인용을 적용한다. 문자열의 스프레드시트 수식 시작을 무력화하고 숫자 좌표의 음수는 유지한다. 시간대는 내보내기 시점에 고정한다. 예시 CSV/QR에는 예시 표시와 별도 파일명을 적용한다.

동의 철회나 수집 세대 변경 후에는 보류 중인 Android 저장 요청을 실행하지 않는다. P 이탈 시 QR 대화상자를 닫고 문서 저장 결과도 무시한다. 이미 휴대폰/파일로 꺼낸 사본은 차량의 동의 철회로 지워지지 않는다고 안내한다.

## 검증

Kotlin CSV 인용·수식·한글·시각·빈 좌표·중단 기록 및 압축 링크 왕복·QR 분할 무손실/인코딩 테스트. Node에서 브라우저 CSV 생성과 schema 검증 테스트. Android 단위 테스트/빌드/lint, 실제 Kotlin 생성 링크를 브라우저에서 열어 CSV 다운로드를 비교한다. 기존 업무용 월간 viewer는 수정하지 않는다.
